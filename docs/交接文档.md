## 2. 数据源盘点（2026-09-10）

现有资产散落在两个在线平台，需导入 MySQL。

### 2.1 团队表格（SeaTable）·「2026学术科创部」工作组

| base | 表 | 内容 | 对应 schema |
|------|-----|------|------------|
| 学术科创部总表 | 成员表 | 21 名成员：姓名/岗位/性别/专业/手机号/学号/民族/政治面貌/邮箱 | `member` + `position` |
| 朋辈导师总表 | 名单(64) / 风采展示(64) | 名单：学院/学号/姓名/专业/联系方式；风采：个人照/个人介绍/寄语 | `member`（对外卡片，**本期不导入**） |
| 知识行囊台账 | 课程介绍(29)/启航指南/资料收集/学习工具 | 项目台账，含「对接负责人」「课程负责人」分工 | `activity` + `participation` |

### 2.2 团队表格（SeaTable）·「2025学术科创部」工作组（历史）

- 人员情况(25)：招新报名档案（志愿/优势/经历/荣誉/技能/意向部门）
- **工作完成情况(7)：姓名 / 学号 / 工作模块 / 工作内容 / 工时** ← 参与记录的现有雏形
- 2025级朋辈导师名单(63)、部门任务规划、团建意见征集

> 历史数据本期不导入，仅作字段设计参考。

### 2.3 团队云盘（Seafile）·「2026学创部」库（约 2.6GB）

- 交接资料按模块组织：活动策划与主持、早期科研与立项、小先生学业帮扶、朋辈导师工作、推文与新闻稿、部门汇报与学术讲座
- 含大量 docx/xlsx/pptx（策划案、主持词、名单、分工表、工时表）
- 这些文档是后续补录 `activity` / `participation` 的素材来源

### 2.4 同步方式

| 平台 | 方式 |
|------|------|
| 团队表格 | SeaTable API 或持久化浏览器脚本（账号密码/CAS） |
| 团队云盘 | Seafile API（API token）或持久化浏览器脚本 |

**同步方向**：单向导入为主（在线平台 → MySQL），MySQL 作为权威源；写回在线平台视需要。

## 3. 初始化步骤

```bash
# 1. 建库建表
mysql -u root -p < schema/schema.sql

# 2. 导入活动系列（19 项）
mysql -u root -p scitech_kb < data/activities-seed.sql

# 3. 导入当届成员（21 人）——  敏感数据，走内部授权后导入，勿入库明文到公开仓库
# 4. 补录活动场次 + 参与记录（从在线台账/云盘文档整理）
```

**优先级**：先跑通「建表 → 活动系列 → 成员」，再做「参与记录」，最后接经验库。

---

## 4. 敏感数据与合规

- 成员表含**学号、手机号、邮箱**等敏感字段
- 导入前需确认成员知情/授权（非本部门成员走隐私声明，见需求文档 §5.1）
- **真实成员数据不得提交到本仓库**（本仓库只放结构、说明、脱敏样例）
- 敏感字段在接口层按角色脱敏
